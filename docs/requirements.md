# 需求與範圍

## 已上線

| 角色 | 需求 | 現行規則 |
|---|---|---|
| 跑友 | 查活動與即時名冊 | 顯示活動日期、時間、集合地點、名額與名冊。 |
| 跑友 | 報名或修改 | LINE 與一般瀏覽器均可使用。暱稱和預計跑量／配速必填，備註選填。同一活動、同一識別值更新既有報名。 |
| 跑友 | 取得名額或候補 | 額滿後的新報名可列為候補。 |
| 主辦人 | 開關報名及核對結果 | 在 Activities 設定 Open 或 Closed，透過 Registrations 核對結果。GAS 只在活動開放時受理新增與修改。 |

## 現行限制

- 取不到 LINE 身分時，前端產生臨時識別值。重新開頁可能換值，導致同一人留下兩筆。GAS 尚未驗證請求中的 LINE 識別值。
- 前端送出提示無法區分正取、候補和後端拒絕。以 GAS 回應及試算表實際結果驗收。
- 顯示人數包含候補。公開名冊顯示暱稱、跑量／配速、備註與狀態。
- 公開截止路由已移除。主辦人手動改表，本輪未新增自動記錄截止時間的機制。

## 暫緩項目

強制 LINE 登入、後端驗證 LINE 憑證、Bot／Group ID、群組自動公告及候補遞補規則。主辦人可手動公告經同意公開的內容。
