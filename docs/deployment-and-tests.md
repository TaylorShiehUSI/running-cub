三個網址均改跑以第 7 版為基礎的修正版。其他歷史網址及舊客戶端完整相容性未列入驗收。封存前先盤點相依網頁及自動化。

## 本次實測

隔離後端八項通過：

1. 指定場次的截止請求被拒且資料無異動。
2. 未指定場次的截止請求同樣被拒。
3. 開放場次可新增報名。
4. 同場同識別值可更新原列。
5. LINE 格式的假識別值可新增。
6. 截止場次可唯讀查詢。
7. 截止後新增及修改均被拒。
8. 手動切回開放後恢復受理。

隔離 Web App 的 GET 成功回傳測試名冊。上線後確認第 8、9、10 版皆無公開截止分支，三個正式端點的 GET 均回傳活動與名冊，電腦瀏覽器的正式頁顯示已連線且開放報名。寫入測試在隔離表執行。LINE 內建瀏覽器實機與額滿候補未列入本次八項驗收。

## 日後發布與回退

1. 核對正式前端使用的部署 ID 與版本，確認程式差異。
2. 在獨立試算表與假資料驗收，保留 GAS 回應與資料列差異。
3. 編輯既有正式部署並選用新版本，核對 /exec、執行身分與存取設定。
4. 以唯讀 GET 和報名頁確認活動與名冊。寫入與截止測試留在隔離環境。

優先修正新版並重新驗收。回退第 7、4 或 3 版會重新開放公開截止路由，只作受控應急評估。公開文件僅放測試假資料及驗收摘要。
